# Мелочь Инк: Android-приложение

Игра работает внутри WebView. Весь код игры лежит в `app/src/main/assets/index.html`.
Прогресс хранится на телефоне. Код сохранения из вкладки «Ещё» переносит прогресс между браузером и приложением.

## Как получить APK без установки Android Studio

1. Создай на github.com пустой репозиторий.
2. Загрузи в него всё содержимое этой папки вместе со скрытой папкой `.github`
   (на компьютере: Add file → Upload files, перетащи файлы и папки).
3. Открой вкладку **Actions**, выбери **Build APK** и нажми **Run workflow**.
   Сборка идёт 3–5 минут.
4. Когда она станет зелёной, открой её и скачай **meloch-inc-apk** из блока Artifacts.
   Внутри будет `app-debug.apk`.
5. Передай файл на телефон и установи. Android попросит разрешить установку из этого источника.

## Через Android Studio

Открой папку как проект, дождись синхронизации и выбери Build → Build APK(s).
Файл будет в `app/build/outputs/apk/debug/app-debug.apk`.

## Заметки

- Шрифты игры подгружаются из интернета. Без сети используется системный шрифт, игра работает так же.
- APK подписан отладочным ключом. Для публикации в Google Play нужен релизный ключ.
- Приложение всегда в вертикальной ориентации. Кнопка «назад» сворачивает игру, а не закрывает её.
